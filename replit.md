# Game Asset Pack

This repository is a collection of game-ready assets intended for use in a game or interactive app build.

## Asset Categories

| Folder | Contents |
|---|---|
| `BoxesBanners/` | UI boxes, banners, and text boxes — PNG + SVG, multiple color variants |
| `ButtonsIcons/` | Icon buttons (large & small) — circle, rounded, square — PNG + SVG |
| `ButtonsText/` | Text buttons, on/off toggles, text fields, premade buttons — PNG + SVG |
| `Icons/` | Game HUD icons: hearts, stars, coins, keys, audio, menu, etc. — PNG + SVG |
| `Sliders/` | Scroll bars and sliders — PNG + SVG |
| `Medieval_Village_MegaKit/` | Modular medieval building 3D assets — OBJ + glTF, with textures |
| `Stylized_Nature_MegaKit/` | Stylized trees, rocks, grass, flowers — OBJ + glTF, with textures |
| `KayKit_Adventurers_2.0_FREE/` | KayKit character pack with animations and textures |
| `Modular Character Outfits - Fantasy[Standard]/` | Fantasy character outfit/clothing 3D assets |

## Formats

- **UI sprites**: PNG (raster) and SVG (vector)
- **3D models**: OBJ/MTL and glTF/GLB
- **Textures**: PNG diffuse, normal maps, etc.

## Notes

- There is no runnable code in this repo — it is a pure asset library.
- Assets are intended to be imported into a game engine (Unity, Godot, Unreal, Three.js, etc.) or app.
- The build/game project will be developed separately on GitHub.

## User Preferences

- Project will be built on GitHub; this Replit repo serves as the asset source.
